# Getting Started with Next.js

Next.js is a React framework that gives you everything you need to build fast, production-ready web applications. In this post we'll walk through the basics.

## Why Next.js?

Next.js handles routing, server-side rendering, and image optimization out of the box — things you'd otherwise have to wire up yourself.

## Creating your first page

Pages live inside the `app/` directory. Each folder with a `page.js` file becomes a route automatically.

```js
export default function Page() {
  return <h1>Hello, world!</h1>;
}
```

That's all it takes to create a new route at `/`.

## What's next?

From here you can explore layouts, data fetching, and dynamic routes. Next.js grows with you — start simple and add complexity only when you need it.
